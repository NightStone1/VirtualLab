Виртуальный методический комплекс по дисциплине "Электрические машины"

Авторы:
Бабичева Екатерина Анатольевна;
Бибко Эдуард Александрович.

Год разработки: 2026.

Проект разработан в рамках выпускной квалификационной работы и предназначен для демонстрации виртуальных лабораторных работ по дисциплине "Электрические машины".

Состав проекта:
1. Assets — исходные ресурсы Unity-проекта.
2. Packages — сведения о пакетах Unity.
3. ProjectSettings — настройки Unity-проекта.
4. Build — готовая сборка программного комплекса, если она включена в передаваемый архив.
5. README.txt — описание проекта и состава архива.
6. LICENSE.txt — условия использования программного комплекса.
7. SUBMISSION_MANIFEST.txt — перечень передаваемых материалов.

Для открытия исходного проекта необходимо использовать Unity-версию, совместимую с проектом. Для запуска готовой сборки следует открыть исполняемый файл из папки Build, не удаляя сопутствующую папку данных и библиотечные файлы.

Использование программного комплекса в учебном процессе АМТИ допускается в рамках подписанного акта о внедрении. Дальнейшее распространение, модификация, передача третьим лицам, публикация исходного кода и использование за пределами указанного внедрения допускаются только с письменного согласия авторов.
